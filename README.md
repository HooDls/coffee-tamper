# Tamper — демо-сайт кофейни

Одностраничный сайт без сборки и серверной части: HTML + CSS + JS. Шрифты (Oswald, Golos Text) лежат в папке `fonts/`, сайт не зависит от внешних сервисов.

Фишка: конструктор напитка. Гость выбирает напиток, объём, подачу (горячий или со льдом), молоко, сироп и добавки. Стакан перерисовывается вместе с выбором, цена считается сразу. Напитки, еда из меню и зерно собираются в один заказ с выбором времени выдачи.

## Что поменять под клиента
Всё в начале `js/main.js`, блок `CONFIG`:
- `shopName` — название кофейни
- `telegram` — ник в Telegram без @
- `whatsapp` — номер в формате 79001234567
- `timezone` — часовой пояс кофейни (например `Europe/Moscow`, `Asia/Almaty`)
- `openMinutes`, `closeMinutes` — часы работы в минутах от полуночи (8:00 = 480, 21:00 = 1260)
- `stepMinutes`, `leadMinutes`, `lastPickupBeforeClose` — шаг времени выдачи, время на приготовление, последний слот перед закрытием

Напитки, размеры и цены: массив `DRINKS` в `js/main.js`. Молоко, сиропы и добавки: `MILKS`, `SYRUPS`, `ADD_SHOT`, `ADD_CREAM`.
Блюда меню: `index.html`, секция `#menu` (атрибуты `data-name` и `data-price`; цена в тексте тоже меняется вручную).
Зерно: секция `#zerno`. Адрес, телефон, FAQ, текст «О нас» — прямо в `index.html` (в демо они вымышлены).

## Как работает заказ
Бэкенда нет. Форма собирает текст заказа и открывает Telegram или WhatsApp с готовым сообщением, текст также копируется в буфер. Оплата на кассе, поэтому платёжных данных сайт не принимает. Нечего взламывать, нечего хранить.

Время выдачи считается по часовому поясу кофейни, а не гостя. Если кофейня закрыта или слоты на сегодня закончились, сайт сам предлагает завтра.

## Публикация на GitHub Pages
1. Создайте репозиторий (Public) и загрузите содержимое папки (`index.html` в корне).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

## Проверено
Chromium: 1440 / 1024 / 820 / 390 / 320 px, без горизонтального скролла и ошибок в консоли; клавиатура и фокус; axe-core (WCAG 2 A/AA) без нарушений; все комбинации цен конструктора, корзина, время выдачи в разные часы суток, маска телефона, проверка формы, текст сообщения, копирование.

Демо-проект: кофейня, адрес и телефон вымышлены.
